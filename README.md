# javascript-lotto-precourse

## 구현할 기능 목록

### 1. 로또 구입 금액 입력 및 검증

- [x] `"구입금액을 입력해 주세요."` 안내 문구를 출력한다.
- [x] 사용자로부터 구입 금액을 입력받는다.
  - [x] **[예외]** 입력값이 1,000원으로 나누어 떨어지지 않으면 에러를 발생시킨다.
  - [x] **[예외]** 입력값이 1,000원 미만의 숫자일 경우 (0, 음수 포함) 에러를 발생시킨다.
  - [x] **[예외]** 입력값이 숫자가 아닌 문자(공백 포함)를 포함하고 있을 경우 에러를 발생시킨다.

### 2. 로또 발행 및 번호 출력

- [ ] 유효한 구입 금액에 맞춰 구매한 로또의 총 개수를 계산한다.
- [ ] 구매 개수를 출력한다. (예: `8개를 구매했습니다.`)
- [ ] 구매 개수만큼 로또를 발행한다.
  - 각 로또는 1~45 사이의 중복되지 않는 숫자 6개로 구성된다.
- [ ] 발행된 모든 로또의 번호를 한 줄에 하나씩 출력한다.
  - 각 로또 번호는 오름차순으로 정렬하여 출력한다. (예: `[8, 21, 23, 41, 42, 43]`)

### 3. 당첨 번호 입력 및 검증

- [ ] `"당첨 번호를 입력해 주세요."` 안내 문구를 출력한다.
- [ ] 사용자로부터 쉼표(`,`)로 구분된 당첨 번호 6개를 입력받는다.
  - [ ] **[예외]** 쉼표로 구분된 숫자의 개수가 6개가 아니면 에러를 발생시킨다.
  - [ ] **[예외]** 1~45 범위를 벗어나는 숫자가 포함되어 있으면 에러를 발생시킨다.
  - [ ] **[예외]** 중복된 숫자가 포함되어 있으면 에러를 발생시킨다.
  - [ ] **[예외]** 숫자가 아닌 문자(공백 포함)가 포함되어 있으면 에러를 발생시킨다.

### 4. 보너스 번호 입력 및 검증

- [ ] `"보너스 번호를 입력해 주세요."` 안내 문구를 출력한다.
- [ ] 사용자로부터 보너스 번호 1개를 입력받는다.
  - [ ] **[예외]** 1~45 범위를 벗어나는 숫자일 경우 에러를 발생시킨다.
  - [ ] **[예외]** 숫자가 아닌 문자(공백 포함)일 경우 에러를 발생시킨다.
  - [ ] **[예외]** 이미 입력된 **당첨 번호**와 중복될 경우 에러를 발생시킨다.

### 5. 당첨 통계 계산 및 결과 출력

- [ ] 구매한 모든 로또와 당첨 번호, 보너스 번호를 비교하여 각 로또의 등수를 결정한다.
- [ ] 등수별 당첨 개수를 집계한다. (3개 일치 ~ 6개 일치)
- [ ] `"당첨 통계"` 헤더를 출력한다.
- [ ] 5등부터 1등까지의 당첨 내역을 정해진 형식에 맞춰 순서대로 출력한다. (예: `3개 일치 (5,000원) - 1개`)
- [ ] 총 투자금 대비 총 당첨금의 수익률을 계산한다.
  - 수익률은 소수점 둘째 자리에서 반올림하여 첫째 자리까지 표시한다. (예: `62.5%`)
- [ ] 최종 계산된 수익률을 출력한다. (예: `총 수익률은 62.5%입니다.`)
